### Stencil buffer (Requirement 3) — REVERTED
- Implemented `Stencil { Ref 10; Comp Less; Pass IncrSat }` in both `Gsplat.shader` and `GsplatGlobal.shader`.
- **Caused splats to disappear completely.** Root cause: URP writes to the stencil buffer during the opaque pass; by the time splats render in the Transparent queue, the stencil value is already ≥ 10, so `Comp Less` fails for every fragment.
- Reverted stencil blocks from both shaders. Stencil capping requires a `WriteMask`/`ReadMask` on specific bits to avoid URP conflicts — deferred to a follow-up ticket.

### Alpha threshold tuning
- Initially set threshold to `15/255`. Verified splats still render.
- Softened to `10/255` (~3.9% alpha) after visual review as a balance between fill-rate savings and visual fidelity. The `15/255` threshold was slightly aggressive for our trained NeRFs.

### Scene changes
- Removed redundant `ChristmasTree` splat from `SampleScene.unity`.
- Added second splat to `SplatControllerHUD.splats[]` array.
- Cleared stale `preloadedAssets` from `ProjectSettings.asset`.

### Decisions
- **10/255 over 15/255:** 10/255 ≈ 3.9% alpha cutoff. Still a 10x improvement over the original 1/255 ≈ 0.4%. Visually indistinguishable from baseline on our scenes but measurably reduces GPU fill-rate work.
- **No stencil for now:** URP stencil conflict makes this unsafe without bit masking. Revisit when URP Renderer Features are better understood.
- **Embedded package committed to git:** The entire `com.arloopa.unitysplats/` directory is now tracked. This is intentional — it contains our custom shader modifications and is small enough (~200KB of source).

### On-Device Benchmark Results (S20 FE)

Benchmarked two progressive stages against the 14 FPS unoptimized baseline (FTW-30) using `MobilePerformanceHUD`:

1. **Strategy 1 — GameObject Tuning Only (Sort 3rd frame + async upload):**
   - Scene: Cafe Table (164,710 splats).
   - Metrics: **16 FPS avg, 14 FPS 1% low**.
   - Peak RAM/VRAM: 7.4 GB / 7.0 GB, Battery Drain: ~60%/hr, Thermals: Minor.
   - Finding: A minor +2 FPS gain confirms that CPU/GPU sorting latency and buffer uploads were not the bottleneck causing 14 FPS.

2. **Strategy 2 — Full CDRIN Pipeline (Alpha Discard 10/255 + Quad Rescaling + Sort 3rd Frame + Async Upload):**
   - Scene: Cafe Table (164,710 splats).
   - Metrics: **20–21 FPS avg, 15 FPS 1% low**.
   - Peak RAM/VRAM: 7.4 GB / 7.0 GB, Battery Drain: ~60%/hr, Thermals: Minor.
   - Finding: +45–50% FPS improvement over the unoptimized baseline on a dense full-screen scene. Validates that alpha culling and quad shrinking significantly mitigate the mobile fill-rate / overdraw bottleneck.
   - Scene: Luigi (14,526 splats):
   - Metrics: **30 FPS avg, 29 FPS 1% low**. Maxes out the AR Foundation 30 FPS display limit.
