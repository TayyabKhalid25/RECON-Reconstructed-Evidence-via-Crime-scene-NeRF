   contract is left handed, Y up, metres, converted once on the GPU side before export. So the
   file already sent to Tayyab will load sideways in Unity, and that is the missing conversion
   step, not a bug in his code. The frame conversion was already noted as next session's work;
   this makes it blocking for the Unity hand-off rather than optional.
2. **The scene is non-metric.** No `metadata.json` and no `unitScale`, because the capture did not
   place the 170 mm marker at the scene origin. Per `docs/FRAMES.md` a scene without metric scale
   must not be used for any accuracy claim. Recorded explicitly in the Scale checks table. The run
   is valid evidence that the pipeline works end to end and valid for the image-quality metrics;
   it is not usable for the 2 cm positional accuracy objective.
