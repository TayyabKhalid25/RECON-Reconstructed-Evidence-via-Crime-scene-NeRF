## Sitting 2 · Table scale verification & high-quality splat exports

- Executed independent scale verification (FTW-36).
- Wrote `tools/compare_scale.py` to measure the 4ft x 2ft table in both the marker (`1`) and no-marker (`table-nomarker`) reconstructions.
- **Marker Scene:** The marker automatically provided `unitScale = 0.369573`. Applying this to the scene units yielded accurate physical dimensions.
- **No-Marker Scene:** Without a marker, the reconstruction yielded an arbitrary scale. We tested using the table's length (4ft) to compute a scale factor (0.0949), and then used the table's width (2ft) to compute a second scale factor (0.0706) — a >25% disagreement.
- **Key Finding:** The mismatch between the length-derived scale and width-derived scale proves that without a marker, COLMAP does not just lose absolute scale; it introduces geometric warping and aspect ratio distortion.
- **Conclusion:** The ArUco marker provides a reliable, reproducible metric scale and anchors the geometry against warping, making it strictly required for valid forensic distance measurements.
